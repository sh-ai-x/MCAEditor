## Plugins

### Orange Slice

**By MechArt · Included with MCA Editor · Free**

An AI assistant that lives inside MCA Editor and understands your Maya session. Ask it to write scripts, explain errors, refactor code, or look up commands — it can read your open files, see your output panel, and execute code directly in Maya on your behalf.

Orange Slice supports Claude (Anthropic), GPT-4 (OpenAI), and Gemini. Bring your own API key or use it with an MCA subscription.

**Included in:** All MCA Editor licenses
**Requires:** MCA Editor 1.0.0 or later

## Submit a Plugin

Built something useful? Get it listed here.

The plugin directory is open to both free and paid plugins. Listings are manually reviewed to ensure a baseline of quality. There is no fee to submit.

To submit, email [info@mechart.org](mailto:info@mechart.org) with:

- Plugin name and a short description (2-3 sentences)
- What it does and who it's for
- A screenshot or two showing it running inside MCA
- A link to your plugin (a GitHub repository is ideal)

We'll follow up within a few business days.
