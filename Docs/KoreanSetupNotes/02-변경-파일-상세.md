## 신규 생성: `userSetup.py`

위치: `C:\Users\tkd14\Documents\maya\2024\scripts\userSetup.py`

목적: Maya 시작 시 커맨드포트(`:7001` MEL, `:7002` Python)를 자동으로 열기 위함.

```python
import maya.cmds as cmds
import maya.utils as utils


def _mca_open_command_ports():
    """Open Maya's MEL/Python command ports for MCA Editor, skipping ports that are already open."""
    for port_name, source_type in ((":7001", "mel"), (":7002", "python")):
        try:
            cmds.commandPort(name=port_name, sourceType=source_type, echoOutput=True)
        except RuntimeError:
            pass


utils.executeDeferred(_mca_open_command_ports)
```

이후 MCA Editor 플러그인이 로드되면서 스스로 자동 로드 블록
(`# MCA_EDITOR_AUTO_LOAD` ~ `# END_MCA_EDITOR_AUTO_LOAD`)을 파일 끝에
추가함 (플러그인이 자동으로 하는 정상 동작).

## 코드 수정: `mca_maya/maya_window.py` (NameError 버그 수정)

`show_mca_editor()` 함수 안, `editor_was_open` 상태를 저장하는 줄에서
한 번도 정의된 적 없는 지역 변수 `_app_name`을 참조하고 있었음.

```
NameError: name '_app_name' is not defined
```

`_app_name`은 `MCAMayaWindow.__init__()` 안에서만 정의되는 지역 변수였고,
`show_mca_editor()`는 별개의 모듈 레벨 함수라 그 값을 알 수 없는 상태였음.
같은 파일의 다른 위치(`plugin_main.py:137`, `plugin_main.py:287`,
`maya_window.py:1722`)는 매번 `_maya_version`을 import해서 앱 이름을
다시 계산하는데, 이 지점만 그 과정이 빠져 있었음.

**수정**: 새로 계산하는 대신, 바로 위에서 생성된 `_mca_editor_window` 인스턴스가
이미 들고 있는 설정 객체(`_settings`)를 재사용함.

```diff
     # Record that the editor is now open so it auto-opens on next Maya launch.
-    MCASettings(app_name=_app_name).set("editor_was_open", True)
+    _mca_editor_window._settings.set("editor_was_open", True)
```

영향: 이 버그는 "다음 Maya 실행 시 에디터 자동으로 열기" 상태 저장에만
영향을 줬고, 에디터 창이 뜨는 것 자체는 정상이었음.

## Maya 환경설정: Custom 셸프 버튼

`shelf_Custom.mel`은 Maya가 직접 저장/관리하므로, 텍스트 파일을 직접 편집하지
않고 Maya Script Editor에서 아래 Python 코드를 실행하는 방식으로 추가함.

MCA Editor 플러그인이 상태줄의 **Script Editor** 아이콘을 MCA Editor로
덮어쓰기 때문에, Maya의 원래(네이티브) Script Editor에 접근할 별도 경로가
필요해서 셸프 버튼을 하나 추가함:

```python
import maya.cmds as cmds

cmds.shelfButton(
    parent="Custom",
    label="Script Editor",
    annotation="Open Maya's native Script Editor (separate from MCA Editor)",
    image1="commandButton.png",
    sourceType="mel",
    command='tearOffPanel "Script Editor" "scriptEditorPanel" true;',
)
```

최종 구성:

- 상태줄 **Script Editor** 아이콘 / Windows 메뉴 → MCA Editor가 열림
- Custom 셸프의 **Script Editor** 버튼 → Maya 기본 Script Editor가 열림
