# MCA Editor 설치 과정 정리

(작성일: 2026-10-28)

## 1. 무엇을 설치했나

Maya용 스크립트 에디터 "MCA Editor"를 공식 GitHub 소스
([ncomes/MCAEditor](https://github.com/ncomes/MCAEditor), MIT 라이선스, 무료)로 설치함.

Maya의 기본 Script Editor를 대체/보완하는 도구로, 코드 아웃라인, 탭 관리,
출력 패널 등을 제공하며 Maya 안에 직접 도킹되어 동작함.

## 2. 설치 위치

**소스 저장소 (원본):**

**바로가기:**

바탕화면의 "MCA Editor.lnk" — 독립 실행 앱(별도 창 형태)을 바로 실행하는 바로가기.

## 3. Maya에서 사용하는 방법

1. Maya 실행
2. 상태줄의 **Script Editor** 버튼 클릭 → MCA Editor가 Maya 안에 도킹된 창으로 열림 (기본 Script Editor 대신)
3. Custom 셸프 탭의 **Script Editor** 버튼 클릭 → Maya 기본(네이티브) Script Editor를 별도 창으로 열 수 있음

(MCA Editor와 기본 Script Editor 둘 다 사용 가능하도록 구성함)

## 4. 현재 상태

- Maya를 켤 때마다 MCA Editor 플러그인이 자동으로 로드됨
- 커맨드포트도 자동으로 열려서 Python/MEL 코드 실행 및 Maya 연동이 바로 가능함
- 독립 실행 앱과 Maya 내장 플러그인 두 가지 방식 모두 설치되어 있으며,
  현재는 Maya 내장 플러그인 방식을 주로 사용 중
